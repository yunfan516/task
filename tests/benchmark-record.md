# 选题 58：多规模性能实测与复现验证记录

## 一、测试环境说明

- **处理器**：13th Gen Intel(R) Core(TM) i7-13700HX
- **内存**：16 GB
- **操作系统**：Microsoft Windows 11 专业版
- **WASM 运行时**：Node.js v24.15.0（V8 WebAssembly 引擎）/ Edge 浏览器 Web Worker
- **C 编译命令**：`zig cc -target wasm32-freestanding -O2 -nostdlib sort_core.c -Wl,--no-entry -Wl,--export-memory -Wl,--initial-memory=16777216 -Wl,--max-memory=16777216 -Wl,--strip-all -o sort_core.wasm`
- **复现命令**：`node tests/test-cases.mjs 100000` 或 `node tests/test-cases.mjs --multi`
